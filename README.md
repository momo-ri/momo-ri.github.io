# 🧑‍💻 김태리의 세무사& 자격증 도전기 블로그

데브옵스(DevOps) 여정을 기록하고 기술 스택, 자격증 취득 경험을 공유하는 개인 기술 블로그입니다.
(Jekyll + Chirpy Theme 기반)

[![GitHub Pages Status](https://github.com/teddy-wooma/teddy-wooma.github.io/actions/workflows/pages/pages-build-deployment/badge.svg)](https://github.com/teddy-wooma/teddy-wooma.github.io/actions/workflows/pages/pages-build-deployment.yml)

## 🌟 주요 목표 및 콘텐츠

이 블로그는 다음과 같은 내용을 중심으로 운영됩니다.

* **DevOps 여정 기록:** AWS, Docker, Kubernetes, Terraform 등을 활용한 실습 과정 및 프로젝트 경험 공유.
* **자격증 취득 과정:** Azure (AZ-700, AZ-204) 등 클라우드 자격증의 준비 자료 및 상세 후기.
* **기술 스터디:** JavaScript, CS_Study 등 개인 및 그룹 스터디 정리 자료.
* **프로젝트 관리:** CI/CD 파이프라인 구성 및 MSA 기반 프로젝트 경험 공유.


## 🛠️ 기술 스택 및 환경

* **블로그 엔진:** [Jekyll](https://jekyllrb.com/)
* **테마:** [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy)
* **배포 환경:** GitHub Pages
* **주요 기술:** HTML, CSS(Bootstrap), Liquid (Jekyll Templating Language)
